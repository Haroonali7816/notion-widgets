# Notion widgets

Embeddable dashboard widgets for Notion. Use `/embed` in Notion with these links:

| Widget | Link |
|---|---|
| Location (Saarbrücken map, live time, weather) | `https://haroonali7816.github.io/notion-widgets/?w=location&theme=dark` |
| Clock (analog + digital) | `https://haroonali7816.github.io/notion-widgets/?w=clock&theme=dark` |
| Date (day, KW, semester & year progress, calendar) | `https://haroonali7816.github.io/notion-widgets/?w=date&theme=dark` |

Options: `theme=light|dark`, `bg=transparent`, `tz=Europe/Berlin`,
`zones=Asia/Karachi,America/New_York` (clock), `city=…&lat=…&lon=…` (location),
`sem=2026-10-01,2027-03-31&semname=WS 26/27` (date).

Map tiles © Esri · Weather by Open-Meteo.

Live at https://haroonali7816.github.io/notion-widgets/
